## Decisions already locked, do not re-litigate

These were settled by a judged tournament and by the entrant. Build them as written.

- Domain is agent-conduct governance, not promo or referral abuse. Detectors are `scope-violation`, `injected-turn-tool-call`, `cross-tenant-egress`, `privilege-sequencing`.
- The Examiner is deterministic code, roughly 200 lines, not an LLM. It is the only principal with read access to `holdout_sealed`.
- The policy DSL is deny-only. There is no allow verb. Model Armor verdict fields are first-class predicates.
- The promotion gate is two-sided plus monotonic: attacks blocked must rise, benign pass rate must not fall, the new version's denial set must be a superset of the current one.
- Attestation has three states, `attested`, `quarantined`, `unknown`. It gates authority, never availability. A quarantined version keeps enforcing and freezes promotion.
- Agent Gateway is droppable and sits first on the Day 4 cut list. Cloud Run is the pre-approved fallback host for every agent.
- Refusals are recorded as links in the chain, alongside approvals.
